# portfolio-web

Personal portfolio of Aditya Surya Putra, a developer from Indonesia who builds AI agents, automation
tools and web apps.

Live: https://portfolio-web-roan-pi-22.vercel.app

## Pages

- **Home and Projects:** selected work with case details per project (`/projects/[id]`).
- **About and Achievements.**
- **Smart Talk:** a chat page for asking about my work.
- **Contact.**
- A command palette (Ctrl/⌘ + K) to jump between pages.
- Live GitHub and WakaTime stats through small API routes (`/api/github`, `/api/wakatime`).

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion. Deployed on Vercel.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
